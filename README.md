# Santhosh Markonda — Portfolio

A responsive React + Vite portfolio starter.

## Run locally

```bash
npm install
npm run dev
```

## Before deploying

1. Replace the email, phone, LinkedIn URL and Google Drive resume URL in `src/main.jsx`.
2. Add your professional photo as `public/profile.jpg` and update the hero placeholder in `src/main.jsx` if desired.
3. Add your PDF resume as `public/resume.pdf`.
4. Confirm the E-Commerce deployment URL and add the actual public RiseUpp deployment URL.
5. Replace Project Three, Four and Five with real projects or remove unused cards.
6. Replace the contact form's `mailto:` behavior with Formspree or your own backend if you want messages delivered without opening the visitor's email app.

## Deploy to Vercel

Push this folder to GitHub, import the repository in Vercel, and use the default Vite settings:
- Build command: `npm run build`
- Output directory: `dist`
